# Machine Learning Labs 

This repository houses all the machine learning techniquies discussed in EDS 232. 

Lab 1 - Intro to scikit-learn (sklearn), a Machine Learning Library. Creates a supervised regression using the Algerian Forest Fires dataset. 
Lab 3 - Using CDC/ATSDR Environmental Justice Index (EJI) to measure the cumulative environmental and social burdens faced by communities across the United States at the census-tract level through K Nearest Neighbor. 
Lab 4 - With continuous sensor data from the Hudson River during Hurricane Irene (August 25 – September 5, 2011), collected by HRECOS, I used Cross-Validation and Polynomial Regression to study the relationship ationship between turbidity and DO. 
Lab 5 - Fit Ridge and Lasso regression models to understand Lambdas effect on bias, variance, correlated and irrelevant features. 
Lab 6 - Build and tune a single decision tree to predict forest cover type from wilderness cartographic data. 
Lab 7 - Build and tune three ensemble methods to predict forest cover type from wilderness cartographic data. 
Lab 8 - Compare the three different Support Vector Classifier Kernels (Linear, RBF, Polynomal) and Random Forests to see which performs best with two-class, two-dimensional dataset shaped like two half-circles.
